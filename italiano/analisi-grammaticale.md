# ✏️ Piccola sfida

Nella frase:

> **Il cane corre velocemente nel parco.**

Rispondi:

1. Qual è il **nome**?
2. Qual è il **verbo**?
3. Qual è l'**avverbio**?
4. Qual è l'**articolo**?
5. Riesci a trovare la **preposizione**?

---

# ✅ SOLUZIONI

> **Non leggere questa parte prima di aver completato gli esercizi!**

## Soluzione esercizio 1

**Il piccolo gatto nero dorme tranquillamente sul divano.**

| Parola | Analisi |
|---|---|
| **Il** | articolo determinativo |
| **piccolo** | aggettivo qualificativo |
| **gatto** | nome comune di animale |
| **nero** | aggettivo qualificativo |
| **dorme** | verbo |
| **tranquillamente** | avverbio |
| **sul** | preposizione articolata (*su + il*) |
| **divano** | nome comune di cosa |

---

## Soluzione esercizio 2

**La mia amica legge un libro interessante.**

| Parola | Analisi |
|---|---|
| **La** | articolo determinativo |
| **mia** | aggettivo possessivo |
| **amica** | nome comune di persona |
| **legge** | verbo |
| **un** | articolo indeterminativo |
| **libro** | nome comune di cosa |
| **interessante** | aggettivo qualificativo |

---

## Soluzione esercizio 3

**I bambini giocano allegramente nel grande giardino.**

| Parola | Analisi |
|---|---|
| **I** | articolo determinativo |
| **bambini** | nome comune di persona |
| **giocano** | verbo |
| **allegramente** | avverbio |
| **nel** | preposizione articolata (*in + il*) |
| **grande** | aggettivo qualificativo |
| **giardino** | nome comune di cosa |

---

## Soluzione della piccola sfida

**Il cane corre velocemente nel parco.**

1. Nome → **cane** (anche *parco* è un nome)
2. Verbo → **corre**
3. Avverbio → **velocemente**
4. Articolo → **il**
5. Preposizione → **nel** (*in + il*)

# 🧠 Da ricordare

```text
PAROLE
│
├── NOME
│   └── indica persone, animali o cose
│
├── ARTICOLO
│   └── accompagna il nome
│
├── AGGETTIVO
│   └── descrive o specifica il nome
│
├── VERBO
│   └── indica un'azione, uno stato o un modo di essere
│
├── AVVERBIO
│   └── precisa soprattutto come, quando o dove
│
└── PREPOSIZIONE
    └── collega parole della frase
```

### Regola veloce

**Nome → chi o che cosa?**  
**Aggettivo → com'è?**  
**Verbo → che cosa fa?**  
**Avverbio → come? quando? dove?**
